### ⚖️ Libyan Legal AI Assistant

An AI assistant that answers questions about Libyan law in Arabic. It retrieves the relevant laws and articles first, then generates an answer grounded in the actual text, with references so users can verify the source.

> ⏸️ The live demo is offline for now because of hosting and API costs.

> ⚠️ This tool provides legal information, not legal advice.
